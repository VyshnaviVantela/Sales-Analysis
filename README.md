# Sales Analysis Dashboard — Power BI

## Project Overview
This project focuses on analyzing sales performance and presenting key business insights through an interactive Power BI dashboard.

## Tools & Technologies
- Power BI
- DAX
- Power Query
- SQL

## Dashboard Features
- Total Sales and Profit Percentage KPIs
- Average Order Value analysis
- Sales variation and performance tracking
- Top-performing product categories and salespeople
- Interactive slicers for filtering and drill-down analysis

## Key Skills Demonstrated
- Data cleaning and transformation
- Data modeling and DAX calculations
- KPI development
- Interactive dashboard design
- Business performance analysis

## Dashboard Details

### 1. Sales Dashboard

**Key Performance Indicators (KPIs)**
- Total Sales
- Total Orders
- Total Profit
- Total Customers

**Dashboard Visualizations**
- **Sales Trend by Month:** Line chart displaying monthly sales performance.
- **Sales by Category:** Column chart comparing sales across product categories.
- **Sales by State:** Bar chart showing sales across different states.
- **Top 5 Products:** Table displaying product name, quantity, sales, and profit for the five highest-selling products.
- **Payment Methods:** Donut chart showing the distribution of orders by payment method.

**Interactive Filters**
- Order Date
- State
- Category
- Payment Method

### 2. Additional Analysis and Challenges

- Average Order Value
- Best-Selling Product by Quantity
- Category with the Highest Revenue
- Top-Performing Salesperson
- Average Customer Age
- Completed vs. Cancelled Orders
- Sales, Profit, and Profit Percentage
- Sales Analysis by Gender
- State and Category Sales Matrix
- Monthly Sales and Profit Comparison

### 3. Data Model

The dashboard uses six tables from a MySQL sales database:

- Categories
- Products
- Customers
- Employees
- Orders
- Order Details

### 4. Tools and Technologies

- MySQL — Database creation and sample data
- Microsoft Power BI Desktop — Data modeling and visualization
- DAX — Measures and calculations
